# Movie Box Office Revenue Analysis

An R-based analysis of the TMDB 5000 Movie Dataset examining how budget, genre, and other production characteristics relate to worldwide box-office revenue.

## Project workflow

- Clean and standardize the source data.
- Explore revenue distributions and relationships between key variables.
- Visualize budget, genre, and performance patterns.
- Estimate regression models to identify meaningful predictors of box-office outcomes.
- Present the methods, findings, and interpretation in a final report.

## Repository contents

| File | Purpose |
| --- | --- |
| `467_project-copy.Rmd` | R Markdown source containing the analysis and visualizations |
| `tmdb_5000_movies.csv` | TMDB 5000 source dataset used by the project |
| `Final_Report.pdf` | Final analytical report |

## Tools

- R
- tidyverse, including `dplyr` and `ggplot2`
- R Markdown
- Regression analysis and exploratory data visualization

## Reproducing the analysis

Open `467_project-copy.Rmd` in RStudio with the CSV file in the same project directory. Install the packages referenced in the document, then knit the R Markdown file to regenerate the analysis output.
